通过之前的安装文档，你已经成功安装了 Halo，在首次访问网站的时候会自动跳转到初始化页面，你需要完成这个步骤才能正常使用 Halo。

![Setup](/img/setup/setup-2.26.png)

表单项说明：

1. **语言**：Halo Console、个人中心和系统页面默认使用的语言。
2. **外部访问地址**：站点对外提供访问的完整地址，例如 `https://www.example.com`。Halo 会根据当前请求自动填写，请确认协议、域名和端口正确。
3. **站点标题**：网站的名称，将会显示在浏览器标签页上。
4. **用户名**：初始管理员的用户名。
5. **电子邮箱**：初始管理员的邮箱地址。
6. **密码**：初始管理员的密码。
7. **确认密码**：重复输入密码以验证是否匹配。

输入完成之后点击**初始化**按钮即可完成初始化。初始化完成后将进入 Console；如果登录状态失效，可以使用刚才设置的用户名或已验证邮箱和密码重新登录。

## 初始化中断后继续

初始化开始后，Halo 会先记录初始化状态，再依次创建管理员、写入基础设置、导入默认数据并安装预设主题和插件。只有所有步骤都成功，初始化才会被标记为完成。

如果初始化过程中断，例如进程退出、请求被取消或预设插件安装失败，再次访问站点时会回到初始化页面，并提示继续未完成的初始化：

- **用户名**会沿用上一次初始化使用的用户名，并且不可修改。
- 如果管理员账号已经创建，需要输入首次设置时使用的密码；Halo 不会重置已有密码。
- 已经完成的步骤会被跳过，缺失的超级管理员角色绑定、默认数据、预设主题和插件会被自动补齐。
- 已有的站点标题、语言和外部访问地址不会被覆盖。

该行为从 Halo 2.28.0 开始提供。在 2.5.2 之前创建、没有初始化状态记录的旧站点，Halo 会在启动时自动标记为已初始化，不会要求重新初始化。
