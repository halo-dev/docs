## 主仓库贡献政策

[Halo 主仓库](https://github.com/halo-dev/halo)目前仅接受项目维护者提交的 Pull Request，暂不接受外部贡献者的 Pull Request，包括代码、测试和文档修改。

欢迎通过 Issue 反馈 Bug、提出功能建议，或通过 Discussions 参与讨论。创建 Issue 或参与讨论不代表获得提交 Pull Request 的许可。

## 反馈与讨论

- [GitHub Issues](https://github.com/halo-dev/halo/issues)：反馈 Halo 核心项目的 Bug 或提出功能建议，请提供复现步骤或清晰的需求描述。
- [GitHub Discussions](https://github.com/halo-dev/halo/discussions)：交流使用、部署等问题。

更多反馈渠道和提交建议，请参阅[问题反馈](./issue.md)。

## 维护者开发流程

项目维护者请参阅主仓库的 [Contributing Guide](https://github.com/halo-dev/halo/blob/main/CONTRIBUTING.md)，了解开发环境、提交前检查、Pull Request 流程以及 AI 辅助开发等要求。

## 其他仓库

以上 Pull Request 限制适用于 `halo-dev/halo` 主仓库。文档、插件、主题及其他生态项目的贡献方式，请以各自仓库的贡献指南为准。
