商城模块是 Halo 商城版的一项功能，支持用户基于 Halo 站点创建店铺，上架多种类型的货品，配置商品支付和发货方式。为实体商品、虚拟商品、链接商品等销售场景提供完备的电商解决方案。

## 使用流程

1. 完成[准备工作](./prepare.mdx)，配置[商店设置](./settings.md)、[支付方式](./payments.mdx)和[销售渠道](./sales-channels.mdx)。
2. 创建并发布[产品](./products.mdx)，按需配置[营销活动](./marketing.md)。
3. 在[订单管理](./orders.mdx)中处理付款与发货；顾客可在[商城客户中心](./customer-center.md)查看自己的订单、地址和优惠券。
4. 需要对接外部系统时，配置 [Webhook](./webhooks.md)。
