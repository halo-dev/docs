商城模块是 Halo 商城版的一项功能，支持基于 Halo 站点创建店铺，销售实体商品、虚拟商品、链接商品和订阅产品，并管理支付、订单与交付。

## 使用流程

1. 完成[准备工作](./prepare.mdx)，配置[商店设置](./settings.md)、[支付方式](./payments.mdx)和[销售渠道](./sales-channels.mdx)。
2. 创建并发布[产品](./products.mdx)。销售订阅产品时，继续配置[订阅档次、计划与变更规则](./subscriptions.md)；按需设置[营销活动](./marketing.md)。
3. 在[订单管理](./orders.mdx)中处理付款与发货。虚拟商品配置[数字资源或卡密](./virtual-delivery.mdx)，订阅商品由接入方完成[权益交付与履约上报](../../developer-guide/shop/integration/fulfillment-callback.md)。
4. 顾客可在[商城客户中心](./customer-center.md)管理订单、地址、优惠券和订阅；运营可在控制台[管理订阅](./subscriptions.md#管理订阅)。
5. 需要向外部系统发送业务通知时，配置 [Webhook](./webhooks.md)并检查投递记录。

## 开发与对接

- [商城主题开发](../../developer-guide/shop/theme/overview.md)：定制商城前台页面、样式和交互。
- [商城集成](../../developer-guide/shop/integration/overview.md)：接入方实现订阅事件处理、权益管理与履约回执。
