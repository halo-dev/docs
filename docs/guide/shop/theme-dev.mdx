默认情况下，我们已经在 Halo 本身内置了一套默认的商城模板，如果当前主题没有提供对应的模板文件，则会使用内置的模板文件。

如果你需要定制商城页面或者开发一套全新的商城主题，请阅读开发者指南中的[商城主题开发](../../developer-guide/shop/theme/overview.md)。

- [快速开始](../../developer-guide/shop/theme/quick-start.md)：准备环境并适配第一个商城页面。
- [复用与覆盖模板](../../developer-guide/shop/theme/template-reuse.md)：将内置商城页面融入现有主题。
- [源码二次开发](../../developer-guide/shop/theme/source-development.md)：接管商城前端的布局和交互。
