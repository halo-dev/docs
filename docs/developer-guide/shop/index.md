:::note 仅限 Halo 商城版
本板块面向 [Halo 商城版](../../guide/prepare.md#发行版本)，以 **Halo 商城版 2.27** 为基线。使用其他版本时，请同时核对模板分支和对应版本的 API。
:::

根据开发目标选择入口：

- [主题开发](./theme/overview.md)：复用内置商城模板，定制商品展示、购物车、结算和支付页面。
- [集成](./integration/overview.md)：通过 Webhook 与 RESTful API 对接外部服务，处理订阅权益和履约回执。

开店、商品与订阅配置、订单管理等控制台操作，参见[商城使用指南](../../guide/shop/index.mdx)。
