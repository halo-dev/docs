用于列出所有文章标签的页面，可以用于实现标签墙等功能。

## 路由信息

- 模板路径：`/templates/tags.html`
- 访问路径：`/tags`

## 变量

### tags

#### 变量类型

List\<[#TagVo](#tagvo)\>

#### 示例

```html title="/templates/tags.html"
<ul>
  <li th:each="tag : ${tags}">
    <a
      th:href="@{${tag.status.permalink}}"
      th:text="${tag.spec.displayName}"
    ></a>
  </li>
</ul>
```

### \_templateId

#### 变量值

`tags`
