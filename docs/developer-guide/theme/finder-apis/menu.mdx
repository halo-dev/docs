除 `getByNames(names)` 自 Halo 2.27.0 起可用外，本页其他 API 自 Halo 2.0.0 起可用。

从 Halo 2.26.0 开始，菜单项通过 `MenuItem.spec.menuName` 归属菜单，并通过 `MenuItem.spec.parent` 记录父级。`menuFinder` 返回的 `menu.menuItems` 已按该关系组成树；请通过每个节点的 `children` 渲染子菜单，不要读取已弃用的 `Menu.spec.menuItems` 或 `MenuItem.spec.children`。

## getByName(name)

```js
menuFinder.getByName(name);
```

### 描述

根据 `metadata.name` 获取菜单。

### 参数

1. `name:string` - 菜单的唯一标识 `metadata.name`。

### 返回值

[#MenuVo](#menuvo)

### 示例

```html
<div th:with="menu = ${menuFinder.getByName('menu-foo')}">
  <ul th:with="menuItems = ${menu.menuItems}">
    <li th:each="menuItem : ${menuItems}">
      <a
        th:href="@{${menuItem.status.href}}"
        th:text="${menuItem.status.displayName}"
        th:target="${menuItem.spec.target?.value}"
      >
      </a>
    </li>
  </ul>
</div>
```

## getByNames(names)

自 Halo 2.27.0 起可用。

```js
menuFinder.getByNames(names);
```

### 描述

根据一组 `metadata.name` 批量获取菜单及其菜单项树，适用于需要同时展示多个菜单的场景。

- 按传入集合的迭代顺序返回菜单，重复标识只保留第一次出现的位置。
- 不存在的菜单会被跳过，不会因此报错。
- 传入空集合或 `null` 时返回空列表。
- 每个菜单的 `menuItems` 包含根菜单项，子菜单通过节点的 `children` 获取。

### 参数

1. `names:Collection<string>` - 菜单的唯一标识 `metadata.name` 的集合。

### 返回值

List\<[#MenuVo](#menuvo)\>

### 示例

以下示例按顺序获取两个菜单，并复用下方 [getPrimary() 示例](#getprimary) 中的 `/templates/modules/menu-tree.html` 片段渲染完整菜单树。请将示例标识替换为实际菜单的 `metadata.name`。

```html
<div th:with="menus = ${menuFinder.getByNames({'menu-foo', 'menu-bar'})}">
  <nav th:each="menu : ${menus}">
    <h2 th:text="${menu.spec.displayName}"></h2>
    <th:block
      th:replace="~{modules/menu-tree :: tree(menuItems=${menu.menuItems})}"
    ></th:block>
  </nav>
</div>
```

## getPrimary()

```js
menuFinder.getPrimary();
```

### 描述

获取主菜单。

### 参数

无

### 返回值

[#MenuVo](#menuvo)

### 示例

```html
<nav th:with="menu = ${menuFinder.getPrimary()}">
  <th:block
    th:replace="~{modules/menu-tree :: tree(menuItems=${menu.menuItems})}"
  ></th:block>
</nav>
```

```html title="/templates/modules/menu-tree.html"
<ul th:fragment="tree (menuItems)">
  <li th:each="menuItem : ${menuItems}">
    <a
      th:href="@{${menuItem.status.href}}"
      th:text="${menuItem.status.displayName}"
      th:target="${menuItem.spec.target?.value}"
    ></a>
    <th:block th:if="${not #lists.isEmpty(menuItem.children)}">
      <th:block
        th:replace="~{modules/menu-tree :: tree(menuItems=${menuItem.children})}"
      ></th:block>
    </th:block>
  </li>
</ul>
```
