---
title: 评论数据列表显示字段
description: "使用 comment:list-item:field:create 在 Halo Console 评论列表中添加自定义显示字段，根据当前 ListedComment 配置位置、组件、权限和显隐条件"
---

此扩展点在 Halo 2.28.0 中引入，用于扩展评论数据列表的显示字段。

插件返回的字段会按 `position` 分别显示在列表项的 `start`（左侧）或 `end`（右侧）区域，并渲染在该区域内置内容之前。同一区域内的字段按 `priority` 升序排列；`hidden` 为 `true`，或当前用户不具备 `permissions` 中声明的任一权限时，字段不会渲染。

扩展点接收当前评论的 `ListedComment` 响应式引用。列表数据更新时，字段会使用最新的评论数据重新渲染。

## 定义方式

```ts
export default definePlugin({
  extensionPoints: {
    "comment:list-item:field:create": (
      comment: Ref<ListedComment>,
    ): EntityFieldItem[] => {
      return [
        {
          priority: 0,
          position: "start",
          component: markRaw(FooComponent),
          props: {},
          permissions: [],
          hidden: false,
        },
      ];
    },
  },
});
```

```ts title="EntityFieldItem"
export interface EntityFieldItem {
  priority: number;
  position: "start" | "end";
  component: Raw<Component>;
  props?: Record\<string, unknown\>;
  permissions?: string[];
  hidden?: boolean;
}
```

## 示例

此示例将在评论列表右侧显示评论的资源名称（评论 ID）。

```ts
import type { ListedComment } from "@halo-dev/api-client";
import { VEntityField } from "@halo-dev/components";
import { definePlugin } from "@halo-dev/ui-shared";
import { markRaw, type Ref } from "vue";

export default definePlugin({
  extensionPoints: {
    "comment:list-item:field:create": (comment: Ref<ListedComment>) => {
      return [
        {
          priority: 0,
          position: "end",
          component: markRaw(VEntityField),
          props: {
            description: comment.value.comment.metadata.name,
          },
          permissions: [],
          hidden: false,
        },
      ];
    },
  },
});
```
